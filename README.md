# Periphone downloads

Installers for [Periphone](https://play.google.com/store/apps/details?id=com.guruswarupa.periphone), which turns an Android phone into a wireless camera and microphone for your computer.

- **Phone app:** Google Play.
- **Computer app:** get the installer for your system from the **[latest release](../../releases/latest)**. Each release lists a SHA-256 for every file (`SHA256SUMS.txt`).

This repository holds downloads only.
